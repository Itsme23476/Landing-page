How to Organize Files by Size on Windows and Mac

November 21, 2026·8 min read

Quick answer

On Windows, open the folder in File Explorer, switch to Details view and click the Size column, or type size:>1GB in the search box to filter. On Mac, switch Finder to List view and click the Size column, or press Cmd+F and add a File Size rule. Both systems can also group files into size bands. Use size to decide what to delete or move off the drive, then organize what is left by what the files are.

People usually ask how to organize files by size for one of two reasons. Either the drive is full and they want to know what is eating it, or a folder is a mess and size feels like one more way to bring order to it. The first is a great use of size. The second is weaker than it sounds, and we will get to why.

Sort files by size in Windows File Explorer

  1. Open the folder in File Explorer.
  2. Switch to Details view. On Windows 11 choose View, then Details. On Windows 10 use the View tab and pick Details.
  3. Click the Size column header. One click puts the largest files first, a second click reverses it.
  4. No Size column? Right-click any column header and tick Size.

One thing trips everyone up: the Size column is blank for folders. File Explorer only reports sizes for files, so a folder holding 40 GB of video looks exactly like an empty one. More on fixing that below.

Group files into size bands

Right-click an empty area, choose Group by, then Size. File Explorer splits the folder into labeled sections so you can collapse the small stuff and look only at the heavy files. On Windows 10 and 11 the bands are:

BandFile size
Tiny0 to 16 KB
Small16 KB to 1 MB
Medium1 to 128 MB
Large128 MB to 1 GB
Huge1 to 4 GB
GiganticOver 4 GB

Filter by size with the search box

Sorting only covers one folder. To find big files across a whole drive, open This PC (or any top-level folder) and type a size filter into the search box:

  • size:>1GB finds everything over 1 GB
  • size:>500MB finds everything over 500 MB
  • size:gigantic uses the band names from the table above
  • size:>100MB kind:video combines size with a file kind

Then sort the results by Size. A full-drive search can take a while. If Windows Search is flaky in general, see our guide to fixing Windows Search.

Let Windows show you the big picture

Go to Settings, System, Storage. Windows breaks your drive down by category (apps, documents, pictures, temporary files). On Windows 11, Cleanup recommendations on the same page includes a list of large or unused files you can review.

List the biggest files with PowerShell

If you want a plain list of the twenty largest files under a folder, including everything in its subfolders, open PowerShell in that folder and run:

Get-ChildItem -Recurse -File |
  Sort-Object Length -Descending |
  Select-Object -First 20 FullName, @{n='MB';e={[math]::Round($_.Length/1MB,1)}}

It only reads. Nothing is moved or deleted.

Sort files by size in Finder on Mac

  1. Open the folder in Finder and switch to List view (View, then as List, or Cmd+2).
  2. Click the Size column header to sort. Click again to reverse.
  3. No Size column? Press Cmd+J to open View Options and tick Size.

In the same View Options panel, tick Calculate all sizes. Finder will then total up each folder and show it in the Size column, so folders sort alongside files. It applies to that folder unless you click Use as Defaults.

To group rather than sort, choose View, then Use Groups, and set Group By to Size. Finder buckets the folder into size ranges, the same idea as the Windows bands.

Find large files anywhere on a Mac

Press Cmd+F in Finder, click the first criteria menu, and choose File Size (pick Other and search for it if it is not listed). Set it to is greater than 1 GB and choose This Mac as the scope. Click Save and you have a Smart Folder that always shows your largest files, updated on its own.

For a ready-made view, open System Settings, General, Storage, then click the info button next to Documents. The Large Files tab lists your biggest files with the date you last opened each one, which is the pairing you want for cleanup: big and untouched.

Prefer Terminal? This lists every file over 1 GB in your home folder:

find ~ -type f -size +1G 2>/dev/null

How to see what is inside the big folders

Sorting files is easy. The harder question is usually which folder is the problem, and Windows will not tell you without right-clicking each one and opening Properties. Disk map tools solve this by scanning a drive and drawing it as blocks, where bigger blocks mean bigger folders.

  • WinDirStat (Windows): free and open source, shows a treemap of the whole drive.
  • WizTree (Windows): reads the drive's file table directly, so scans finish very quickly.
  • TreeSize Free (Windows): a folder tree with sizes next to each entry, closer to how File Explorer looks.
  • GrandPerspective (Mac): open source treemap view.
  • DaisyDisk (Mac): a paid, polished take on the same idea.

Moving files into folders by size

If you want actual folders, for example to split a camera dump before uploading or to pull everything over a mail attachment limit out of a project, this PowerShell snippet sorts the files in the current folder into four subfolders. Add -WhatIf to the end of the Move-Item line first for a dry run: it creates the empty folders and prints what would move without moving anything.

Get-ChildItem -File | ForEach-Object {
  $bucket = if     ($_.Length -ge 1GB)   { 'Huge' }
            elseif ($_.Length -ge 100MB) { 'Large' }
            elseif ($_.Length -ge 1MB)   { 'Medium' }
            else                         { 'Small' }
  New-Item -ItemType Directory -Force -Path $bucket | Out-Null
  Move-Item -LiteralPath $_.FullName -Destination $bucket
}

On a Mac, the simplest route is the Smart Folder from earlier: save one per size range, select everything in it, and drag the files where you want them.

Why size is a good filter and a poor filing system

Size tells you how much room a file takes. It says nothing about what the file is. A folder called Large will hold a wedding video, a virtual machine image and an installer you ran once, and none of those belong together.

So treat size as the first pass of a cleanup, not as the structure:

  1. Sort by size and work from the top. The biggest twenty files usually account for most of the space. Delete what is dead, move archives to an external drive or cloud storage.
  2. Check for copies. Large files are often duplicated across Downloads, Desktop and a backup folder. Our guide to finding duplicate files walks through that.
  3. Cross size with age. Big files you have not opened in a year are the safest to archive. See how to find old files.
  4. Organize the rest by what it is. Type, project, client or date all beat size as a way to find things again. We compare those approaches in how file sorting software works.

FAQ

How do I sort files by size in Windows?

Open the folder in File Explorer, switch to Details view (View, then Details), and click the Size column header. Click once for largest first, again for smallest first. If you do not see a Size column, right-click any column header and tick Size. Folders show no value in this column, only files do.

How do I find the largest files on my whole computer?

On Windows, open This PC in File Explorer and type size:>1GB in the search box, or use Settings, System, Storage, Cleanup recommendations. On Mac, open System Settings, General, Storage and click the info button next to Documents to see Large Files. A disk map tool such as WinDirStat, WizTree or GrandPerspective shows the same thing visually.

Why does File Explorer not show folder sizes?

File Explorer only fills the Size column for files, because adding up every folder would slow browsing down. To see a folder's size, right-click it and choose Properties, or use a disk map tool that totals folders for you. On Mac, Finder can show folder sizes if you turn on Calculate all sizes in View Options.

Should I organize my files into folders by size?

Usually not. Size tells you how much room a file takes, not what it is, so folders named Small and Large do not help you find anything later. Size is best used as a filter for cleanup: sort by size, deal with the biggest files first, then organize what is left by what the files actually are.

Can AI organize files by size?
