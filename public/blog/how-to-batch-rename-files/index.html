How to Batch Rename Files on Windows and Mac

August 10, 2026·8 min read

Quick answer

On Windows, select files in File Explorer and press F2 for simple numbered renaming, or use the free PowerToys PowerRename for search and replace, patterns, and a preview. On Mac, select files in Finder, right-click, and choose Rename, which offers Replace Text, Add Text, and Format modes. Both let you undo right after with Ctrl+Z or Command+Z.

Renaming files one at a time is fine for two or three. For fifty screenshots, a folder of invoices, or a batch of photos, you want to rename them all in one pass. Every modern operating system can do this, and one free Windows add-on takes it much further. Here is how, plus an honest note on when renaming is even worth the effort.

Batch Rename on Windows

File Explorer (the quick way)

For simple sequential naming, you do not need any software:

  1. Select all the files you want to rename in File Explorer.
  2. Press F2, or right-click and choose Rename.
  3. Type the base name, for example Vacation, and press Enter.

Windows names them Vacation (1), Vacation (2), and so on. Made a mistake? Press Ctrl+Z right away to undo. This is quick, but it only does numbered names.

PowerToys PowerRename (the power tool)

For anything more than that, Microsoft's free PowerToys includes PowerRename, a proper bulk renamer. After you install PowerToys, select files in File Explorer, right-click, and choose Rename with PowerRename. It gives you:

  • Search and replace on part of a filename, with a live preview before you commit
  • Sequential numbering with padding and custom start values
  • Text formatting such as lowercase, uppercase, or title case
  • Date and photo metadata patterns, so you can prepend a shoot date to every image
  • Regular expressions for advanced patterns, and an undo after the rename

The preview pane is the reason to use it: you see exactly what every file will become before anything changes. For scripting or automation, PowerShell's Rename-Item can do the same from the command line.

Batch Rename on Mac

macOS has a capable batch renamer built into Finder, no downloads required:

  1. Select the files in Finder.
  2. Right-click and choose Rename (it shows the number of items, like "Rename 24 Items").
  3. Pick a mode from the menu:
    • Replace Text: swap one piece of text in the names for another.
    • Add Text: add a prefix or suffix to every name.
    • Format: apply a new name plus a sequential number or a date.

Finder previews the change and applies it instantly. Press Command+Z right after to undo if needed.

Naming Tips That Actually Help

If you are going to rename in bulk, make the new names do some work:

  • Put the date first, as YYYY-MM-DD. Files then sort in chronological order automatically.
  • Be consistent. Pick one format per folder, like 2026-08-10_client_invoice, and stick to it.
  • Avoid spaces and special characters if the files will travel between systems or the web.

FAQ

How do I rename multiple files at once on Windows?

Select the files in File Explorer, press F2, type a name, and press Enter. Windows renames them all with that name followed by (1), (2), and so on. For search and replace or patterns, use PowerToys PowerRename, which adds a preview and undo.

What is the best batch rename tool for Windows?

PowerToys PowerRename is the best free option. It handles search and replace, regular expressions, sequential numbering, and date or photo metadata patterns, with a live preview and undo. File Explorer's built-in rename is fine for simple numbered names.

How do I batch rename files on Mac?

Select the files in Finder, right-click, and choose Rename. Finder offers Replace Text, Add Text, and Format modes, and Format can add a sequential number or date. It is built into macOS, so no extra software is needed.

Can I undo a batch rename?

Yes. In Windows File Explorer, press Ctrl+Z right after renaming. PowerToys PowerRename also has undo. On Mac, press Command+Z in Finder immediately after. Undo works best right away, so check the result before doing anything else.
