How to Get a Better Spotlight Search on Mac

October 30, 2026·8 min read

Quick answer

You can make Spotlight noticeably better without installing anything: turn off result categories you never use, exclude junk folders, and search with operators like kind:pdf, date:yesterday and quoted phrases. For deeper searches, use Finder's search criteria and Smart Folders, or mdfind in Terminal. What Spotlight can't do is find a file by what it means rather than the exact words in it. For that, a semantic search tool like Filect works alongside Spotlight.

Spotlight is great at one job: opening apps fast. Where people get frustrated is file search. You type a word you're sure is in the document, and Spotlight shows you a website suggestion, three emails and a font. Most guides answer this by telling you to replace Spotlight. That's sometimes the right call, but a lot of the frustration comes from default settings and from not knowing how to talk to Spotlight. Fix those first, and then decide whether you need something else.

This guide covers both: the settings and search syntax that make the built-in tool better, and an honest look at where its ceiling is.

Step 1: Cut the Noise Out of Your Results

Out of the box, Spotlight searches almost everything: apps, documents, mail, messages, contacts, events, fonts, system settings, developer files and web suggestions. If you only use it to find apps and documents, most of that is clutter that pushes the file you want down the list.

  1. Open System Settings and go to Spotlight (on macOS Sequoia and earlier it's called Siri and Spotlight).
  2. In the list of result categories, uncheck everything you never search for. Common ones to turn off are Fonts, Developer, Siri Suggestions and Websites.
  3. Keep Applications, Documents, Folders, PDF Documents and anything else you actually look for.

Next, use the privacy list on the same page (the Spotlight Privacy button on most versions of macOS) to exclude folders that only produce junk matches: old backup copies, code dependency folders, exported archives, or a downloads folder full of installers. Excluding them has a second benefit. A smaller index rebuilds faster and is less likely to fall out of date.

Step 2: Search With Operators Instead of Plain Words

Spotlight understands a small search language that most people never use. These work in the Spotlight bar and in Finder's search field:

Type thisWhat it does
kind:pdfOnly PDF files. Also works with image, folder, presentation, movie, email and more.
date:yesterdayOnly items from yesterday. date:today works the same way.
created: or modified:Filter by when a file was made or last changed, followed by a date.
author:"Sam Lee"Files whose metadata lists that author, useful for Office documents and PDFs.
"exact phrase"Matches the words together, in that order.
AND, OR, NOTCombine terms. The operators must be in capitals.

The real power comes from stacking them. invoice kind:pdf date:yesterday finds the PDF invoice you downloaded yesterday instead of every file that mentions invoices. budget kind:presentation NOT draft skips the drafts. Once you get used to adding a kind: to every file search, Spotlight starts to feel like a different tool.

Spotlight also searches inside documents it can read, such as text files, Word documents, Pages files and PDFs with a text layer. So if you remember a phrase from the document, search for that phrase in quotes rather than guessing at the file name.

Step 3: Use the Keyboard Shortcuts That Matter

  • Command + Space opens Spotlight. You can remap it in System Settings, Keyboard, Keyboard Shortcuts if you want it for another tool.
  • Return opens the highlighted result.
  • Command + Return reveals the result in Finder instead of opening it, which is what you want when you need the folder, not the file.
  • Holding Command on a result shows where the file lives, so you can tell two files with the same name apart.

On macOS Tahoe, Spotlight also gained actions and result filters, so it now overlaps a lot more with launchers like Alfred and Raycast. If you've been holding off on a launcher, try the built-in version on Tahoe first.

Step 4: Go Deeper With Finder Search and Smart Folders

Spotlight's bar is built for speed. For a proper search, open a Finder window and press Command + F. You get the same index with a lot more control:

  1. Make sure the scope is set to This Mac, or to the current folder if you want to narrow it.
  2. Click the plus button to add criteria, such as Kind, Last opened date, Created date, Name or Contents. Choose Other from the attribute menu to see dozens more.
  3. Hold Option and the plus button turns into a button with three dots. That adds a group where you can choose Any, All or None, which is how you build "PDFs or Word files, but not anything in Archive" style searches.
  4. Click Save to turn the search into a Smart Folder in the sidebar. It updates itself as new files match.

Smart Folders are underrated. A "Contracts opened this month" or "PDFs added this week" folder does a lot of the organizing work for you, without moving a single file.

Step 5: Use mdfind in Terminal for Precise Searches

If you're comfortable in Terminal, mdfind queries the Spotlight index directly and skips the interface entirely:

  • mdfind "quarterly report" searches names and content, like Spotlight.
  • mdfind -name invoice matches file names only.
  • mdfind -onlyin ~/Documents budget limits the search to one folder.
  • mdls filename.pdf shows every metadata attribute Spotlight stored for a file, which tells you exactly what you can search on.

This is also the fastest way to check whether a file is in the index at all. If mdfind can't find it, Spotlight can't either, and the problem is the index rather than your search.

Step 6: Fix the Index When Results Get Strange

If files you know exist stop appearing, or results feel slow or stale, the index is probably damaged. That often happens after a macOS update. Run mdutil -s / to check that indexing is enabled, and sudo mdutil -E / to erase and rebuild it. Where Spotlight Hits Its Ceiling

Everything above makes Spotlight faster and more precise, but it doesn't change how it works. Spotlight matches the words and metadata you type against the words and metadata it stored. That leaves three gaps that no setting fixes:

  • You don't remember the words. You remember the lease for the apartment you rented in spring, not that the PDF says "tenancy agreement". Spotlight needs the actual words.
  • The file name is useless. Downloads and scans arrive as scan_0043.pdf or IMG_2211.png. If the content isn't text Spotlight can read, there's nothing to match.
  • The answer is a concept, not a keyword. "The spreadsheet with our Q3 ad spend" describes a file perfectly, but none of those words may be in it.

Launchers like Alfred and Raycast don't solve this either. They're faster and more extensible front ends, but for file search they mostly still rely on name and keyword matching. The Bottom Line

A better Spotlight search usually starts with ten minutes of setup: trim the result categories, exclude the folders that only produce noise, and get in the habit of adding kind: and date: to file searches. Finder's Smart Folders and mdfind take it further for anyone who needs precision. If, after all that, your real problem is that you can't remember what the file says or what it's called, no amount of tuning will fix it. FAQ

How do I make Spotlight search better on Mac?

Turn off result categories you don't use in System Settings, Spotlight, and exclude folders full of junk in the privacy list. Then search with operators like kind:pdf, date:yesterday and quoted phrases so results are filtered before you see them.

How do I make Spotlight show only files?

Uncheck the categories you don't want, such as Websites, Siri Suggestions and Fonts, and add a kind: operator to your search, for example kind:pdf or kind:folder. For saved, repeatable file searches, use Finder's Command + F search and save it as a Smart Folder.

Does Spotlight search inside files?

Yes, for file types it can read, including text files, Word and Pages documents, and PDFs with a text layer. Search for a phrase you remember in quotes. It can't match a file by meaning, so you need words that actually appear in it.

Is there something better than Spotlight for finding files?

For launching apps, Alfred and Raycast are popular upgrades. For finding files you can only describe, a semantic search tool like Filect reads file contents, including scans via OCR, and finds files by meaning. Many people use both.
